## Project

Personal portfolio for the domain `leo-dev.es`. Goals: a **minimalist** site built with **Astro** and **Tailwind CSS**, following modern frontend, UI/UX and accessibility best practices.

@AGENTS.md

## Commands

- `npx astro dev --background` — dev server at http://localhost:4321 (`astro dev stop` / `status` / `logs`)
- `npm run build` — production build to `dist/`; `npm run preview` serves it
- `npx astro check` — type-check `.astro`/TS files

No test runner. For visual review, `node ~/.claude/skills/design-taste-frontend/scripts/inspect.mjs http://localhost:4321/` takes screenshots at 1440/768/390 into `.taste-skill/`. Its house rules ban cards, borders and the cream palette, which the owner chose on purpose, so treat those FAILs as expected and only act on layout ones (headline wrapping, overflow, margins).

## Architecture

- **Bilingual single page.** Spanish at `/` (default locale, no prefix), English at `/en/` (Astro i18n in `astro.config.mjs`). Both `src/pages/index.astro` and `src/pages/en/index.astro` only render `src/components/Home.astro` with a `locale`.
- **All copy and project data live in `src/i18n/content.ts`.** The `en` object spreads the `es` projects and overrides only translated fields, so stack, start date, links and images are defined once (only `period` and the prose are translated). Edit text there, not in components.
- **Hero instrument** (`src/components/Instrument.astro`) reads the real Navigation Timing of the current request; it must stay plain text (no `<output>`/live regions) and show `—` without JS.
- **Styling:** Anthropic-inspired: warm ivory page, white cards (`.card`, 24px radius, soft border), one red accent (`--accent`), all as CSS variables in `src/styles/global.css`. **Light only by the owner's choice: do not add a dark theme.** Reduced-transparency and high-contrast overrides exist. Literata for headings (`h1–h3`, `.serif`), Schibsted Grotesk for body/UI, both self-hosted via Fontsource. Shared classes: `.btn` + `.btn-primary/-secondary/-inverse/-outline-inverse`, `.chip`, `.card-lift`, `.link`, `.site-header` (translucent sticky bar).
- **Projects** render as a vertical timeline (newest first, `<time datetime={start}>`), one card per project; order follows the array in `content.ts`. About is a letter card plus a bento of skill groups (`about.skills`).
- **Icons:** `astro-icon` with `lucide:*` (UI) and `simple-icons:*` (tech/brand logos), inlined at build time. Decorative icons get `aria-hidden="true"`.
- **Motion:** masked headline on load plus `[data-reveal]` scroll reveals, armed only when the inline script adds `.js` to `<html>`; all motion has a `prefers-reduced-motion` fallback.
- **Footer art:** the background is shaded ASCII of a real photo ("Sagrada Família 2010" by Jopparn, CC BY-SA 3.0, credited in the footer; the art inherits that licence). It is a transparent PNG of real Menlo glyphs, generated by `python3 scripts/ascii.py <photo> src/assets/ascii/sagrada.png` (needs Pillow; source photo at https://commons.wikimedia.org/wiki/File:Sagrada_Fam%C3%ADlia_2010.JPG). Footer text stays readable through a background-colour halo and a light veil under the small print.
- Project screenshots are in `src/assets/projects/` (1440×1080 captures of the live sites).

## Design and engineering principles

These are the explicit priorities for this repo; apply them to every change:

- **Minimalism:** restrained palette, generous whitespace, clear typographic hierarchy. Avoid decorative UI that doesn't serve content.
- **Static-first, zero JS by default:** prefer plain `.astro` components. Only add client-side islands (`client:*` directives) when interactivity truly requires it.
- **Accessibility (WCAG 2.2 AA):** semantic landmarks (`header`/`nav`/`main`/`footer`), one `h1` per page with logical heading order, a skip-to-content link, visible `:focus-visible` styles, sufficient color contrast in both light and dark themes, meaningful `alt` text, and full keyboard operability.
- **Motion:** keep it subtle and honor `prefers-reduced-motion` (Tailwind `motion-safe:`/`motion-reduce:`).
- **Performance:** use `astro:assets` (`<Image />`) for images, self-host or preload fonts sparingly, and keep Lighthouse scores high.
- **Responsive:** mobile-first Tailwind utilities; no horizontal scroll at small widths.
- **Theming:** define colors/spacing as Tailwind theme tokens rather than ad-hoc values, so light/dark modes stay consistent.
- **SEO:** per-page `<title>`, meta description, canonical URL and Open Graph tags via a shared layout.
